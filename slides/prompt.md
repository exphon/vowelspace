# slide_template_tyoon — 사용법과 요청문(prompt)

마크다운(`.md`)으로 내용을 쓰면, 이 템플릿의 디자인으로 **슬라이드 HTML 한 파일**을 만들어 줍니다. 그림·소리·영상까지 파일 안에 들어가 그 파일 하나만 공유하면 되고, 인터넷 없이도 브라우저에서 발표할 수 있습니다(YouTube만 인터넷 필요).

## 1. 폴더에 든 것

| 파일 | 하는 일 |
|---|---|
| `build.py` | md → HTML 변환기. 파이썬 3.9 이상만 있으면 되고 따로 설치할 것이 없습니다 |
| `slides.md` | **예시 발표**. 모든 배치와 구성 요소를 한 번씩 써 두었습니다. 새 발표는 이 파일을 복사해서 시작하세요 |
| `slides.html` | 예시를 만든 결과(브라우저로 열어 보세요) |
| `img/logo.png` | 로고(성신여대 심볼). 첫 장에는 제목 위에 크게, 나머지 모든 장에는 오른쪽 위에 제목 글자와 같은 크기로, 제목과 같은 높이에 들어갑니다. 다른 로고를 쓰려면 같은 이름으로 바꾸거나 머리말 `logo:`를 고치세요 |
| `img/sample.svg` | 예시 그림 |
| `vendor/mathjax/` | 수식을 그리는 MathJax 3.2.2(Apache License 2.0). 수식이 있는 발표를 만들 때 HTML 안에 함께 넣습니다 |
| `media/sample.mp3`, `media/sample.mp4` | 예시 소리·영상. 내 소리·영상 파일도 `media/`에 둡니다 |
| `prompt.md` | 이 문서 |

## 2. 사람이 직접 쓸 때

1. 이 폴더를 작업 폴더에 복사합니다(예: `~/강의/2027-1/`).
2. `slides.md`를 복사해 새 이름으로 저장합니다(예: `세미나.md`). 그림은 `img/`에 넣습니다.
3. 맨 위 머리말의 `title`, `footer`를 고치고 내용을 씁니다.
4. 터미널에서 만듭니다.

   ```bash
   cd ~/강의/2027-1/slide_template_tyoon
   python3 build.py 세미나.md          # → 세미나.html
   ```

   Windows는 `py build.py 세미나.md`. YouTube를 슬라이드 안에서 재생하려면 `python3 build.py 세미나.md --serve`(만든 뒤 `http://localhost:8000`으로 열림, 끝내려면 Ctrl+C). 다른 폴더의 md도 됩니다: `python3 build.py ~/어딘가/발표.md` (그림은 그 md가 있는 폴더의 `img/` 기준, 로고가 없으면 템플릿 폴더의 로고를 씀).
5. 만들어진 HTML을 브라우저로 열어 확인합니다.
   - **점검**: 주소 끝에 `?check`를 붙여 열면(예: `.../세미나.html?check`) 내용이 넘쳐 글자가 80% 미만으로 줄어든 장을 표로 보여 줍니다. 그런 장은 내용을 줄이거나 두 장으로 나누세요.
   - **도움말(A)**: 발표 중 A 를 누르면 기능과 키·단추를 정리한 표가 뜹니다(Esc 나 A, 바깥을 눌러 닫기). 오른쪽 아래 **？ 도움말** 단추로도 엽니다.
   - 키보드: **A 도움말** · ← → 넘기기 · **O 한눈에 보기** · F 전체 화면 · N 발표자 노트 · G 번호로 이동 · **P 소리·영상 재생/멈춤** · **D 펜 · H 형광펜** · 그림 클릭 확대
   - **한눈에 보기(O)**: 모든 장을 작게 늘어놓습니다. 장을 누르거나 ← → ↑ ↓ 로 고른 뒤 Enter 를 누르면 그 장으로 가고, Esc 나 O 를 누르면 보던 장으로 돌아갑니다. 오른쪽 아래의 **▦ 한눈에** 단추로도 엽니다. 순서를 확인하거나 질문받은 장으로 바로 갈 때 씁니다.
   - 글자 단축키는 **한/영 상태나 대소문자와 상관없이** 동작합니다. 한글 입력 상태에서 `ㅇ`을 눌러도 D(펜)로, `ㅗ`는 H(형광펜)로 알아듣습니다(자판의 자리로 읽음).
   - **판서(펜·형광펜)**: 발표 중 D(펜)나 H(형광펜)를 누르거나 오른쪽 아래 ✏️ 펜 버튼을 누르면 화면 아래에 도구 막대가 나옵니다.
     | 키 | 동작 |
     |---|---|
     | D / H / E | 펜 / 형광펜 / 지우개(누른 선을 통째로 지움). 같은 키를 다시 누르면 끔 |
     | 1~4 | 색 고르기(펜: 빨강·파랑·청록·검정 / 형광펜: 노랑·연두·분홍·하늘) |
     | Z 또는 ⌘/Ctrl+Z | 되돌리기 |
     | C | 이 장의 판서 모두 지우기(Z로 되돌릴 수 있음) |
     | Esc | 판서 끄기(그림은 남아 있고, 다시 그림 클릭 확대가 됨) |
     - 마우스·터치·태블릿 펜 모두 됩니다(펜은 누르는 힘에 따라 굵기가 조금 달라짐). 판서 중에는 손가락으로 밀어 넘기기가 꺼지고, ← → 키로 넘깁니다.
     - 판서는 장마다 따로 남아 앞뒤로 넘겨도 그대로이고, 전체 화면·창 크기를 바꿔도 제자리에 있습니다. **새로고침하거나 파일을 닫으면 지워집니다**(발표 파일 자체는 바뀌지 않음). 인쇄(PDF)할 때는 그린 내용도 함께 나옵니다.
6. 공유: HTML **한 파일**만 보내면 됩니다. PDF가 필요하면 Chrome에서 인쇄 → PDF로 저장(“배경 그래픽” 켜기).

## 3. Claude에게 맡길 때 — 복사해서 쓰는 요청문

아래를 복사해 빈칸을 채워 Claude(Claude Code 등)에게 보내세요. 이 폴더가 작업 폴더 안에 있어야 합니다.

```text
slide_template_tyoon/prompt.md 를 먼저 읽고, 그 안의 "Claude가 따를 작업 순서"와 디자인 원칙대로 슬라이드를 만들어 주세요.

- 주제:
- 청중:                      (예: 동료 교수, 학부 2학년, 학회 청중)
- 분량:     약 __장 / __분 발표
- 핵심 메시지(한두 문장):
- 참고 자료:                  (파일·폴더 경로, 링크. 없으면 "직접 조사")
- 연구·근거 검색:             (필요 / 불필요)
- 첫 장 발표자 정보:          (예: 윤태진 · 성신여자대학교 창의융합대학장 · 영어영문학과 교수 · https://tyoon.net)
- 파일 이름:                  (예: seminar.md → seminar.html)
- 소리·영상:                 (예: media/인터뷰.mp3, https://youtu.be/… 3분 20초부터)
- 그 밖에:                    (스크린샷 넣을 화면, 톤, 꼭 넣을 내용)
```

## 4. Claude가 따를 작업 순서

1. **읽기**: 이 문서와 `slides.md`(예시)를 끝까지 읽고 문법과 구성 요소를 익힌다. `build.py`는 고치지 않는다(디자인을 바꿔야 하면 사용자에게 먼저 묻는다).
2. **구성안**: 청중·분량에 맞춰 부(part)와 장별 제목 목록을 만든다. 25장 이상이거나 요청이 모호하면 구성안을 먼저 보여 주고, 아니면 바로 작성한다.
3. **작성**: 새 md 파일을 만든다(예시 파일 `slides.md`는 그대로 둔다).
   - 맨 위 머리말에 `title`, `footer`(필요하면 `logo`, `output`)를 적는다.
   - 첫 장은 `layout: title` + `::: presenter`(발표자 정보가 있을 때), 부마다 `layout: section` 표지. 마지막 장은 내용에 맞는 제목으로 마무리한다(출처를 인용했으면 "참고문헌", 도구·절차를 소개했으면 "사용법", 그 밖에는 "요약" 등).
   - 말할 내용은 `::: notes`(발표자 노트)에 쓴다. 화면 글은 짧게.
4. **사실 확인**: 통계·연구 결과·인용은 실제로 확인한 출처만 쓰고, 장 아래 `footnote:`나 참고문헌에 링크를 단다. 숫자를 만들어 내지 않는다. 확인하지 못한 내용은 쓰지 않거나 "확인 필요"로 표시한다.
5. **소리·영상**: 파일은 `media/`에 두고 `::: media` 블록으로 넣는다(6장). YouTube는 주소를 그대로 쓰고, 시작 시각이 있으면 `start:`(초)로 적는다. 50MB가 넘는 영상은 `link: 1`로 두고 보고할 때 "media/ 폴더를 함께 공유해야 함"을 알린다.
6. **그림**: 사용자가 준 그림·스크린샷은 `img/`에 두고 상대 경로(`img/파일.png`)로 쓴다. 웹페이지·앱 화면이 필요하면 직접 캡처할 수 있을 때만 쓰고, 캡처할 수 없는 화면(브라우저 메뉴 등)은 HTML 블록으로 그린 뒤 각주에 "설명용 그림"이라고 밝힌다.
7. **만들기·점검**: `python3 build.py 파일.md`로 만들고, 브라우저로 `파일.html?check`를 열어 표시된 장을 줄이거나 나눈다. 가능하면 모든 장을 캡처해 겹침·잘림·빈 그림을 눈으로 확인한다.
8. **보고**: 만든 파일 경로, 장 수, 점검 결과(줄어든 장, 확인하지 못한 것)를 알린다.

## 5. 디자인 원칙 (이 템플릿의 스타일)

- **한 장에 메시지 하나.** 제목만 읽어도 흐름이 이어지게 쓴다(결론형 제목 좋음).
- **목록은 3~6줄**, 한 줄은 한 문장. 핵심어만 **굵게**. 문단 글은 피한다.
- **문체**: 합니다체, 짧은 문장, 전문 용어는 처음에 풀어 쓴다.
- **배치 고르기**: 화면 설명은 `split`, 큰 도표·그림은 `image`, 비교는 `::: cols` 또는 표, 개념 묶음은 `::: cards`, 절차는 `::: flow` 또는 번호 목록, 기억할 한 문장은 `::: note`, 명령어는 `::: cmd`, 수식은 `$…$`와 `::: math`, 소리·영상은 `::: media`(영상 옆 설명은 `::: cols` 안에).
- **색**: 남색(제목)·파랑(강조)·보라·청록(보조)만 쓴다. HTML 블록에서도 새 색을 만들지 말고 기존 클래스를 쓴다(주황 `#f38020`은 "여기를 누르세요" 강조에만).
- **분량 감각**: 1장에 1~2분. 20분 발표면 12~16장.
- **글자 크기**: 내용이 넘치면 자동으로 줄어들지만, 80% 미만(점검 표시)이면 나눈다.

## 6. 문법 한눈에

### 파일 머리말 (맨 위, 모두 선택)

```markdown
<!--
title: 브라우저 탭 제목
footer: 각 장 왼쪽 아래 문구
logo: img/logo.png        (none 이면 로고 없음)
output: 결과파일.html
-->
```

### 슬라이드 나누기와 배치

- 장 사이는 한 줄에 `---`.
- 장 첫 줄의 주석으로 배치를 고른다. 항목은 `|`로 구분한다.

```markdown
---
<!-- layout: split | image: img/화면.png | caption: 그림 설명 | wide: 1 | footnote: 출처 [링크](https://…) -->
# 제목
## 부제(작게)
```

| layout | 모양 |
|---|---|
| `title` | 첫 장(큰 로고, 큰 제목, 부제, 날짜, `::: presenter`). 다른 배치의 장은 오른쪽 위에 작은 로고가 자동으로 들어감 |
| `section` | 부 표지(파란 배경). 제목을 `2 · 이름`처럼 쓰면 큰 숫자 2가 나옴 |
| `default` | 기본(생략 가능) |
| `split` | 왼쪽 글 + 오른쪽 그림(`image`, `caption`, `wide: 1`) |
| `image` | 큰 그림 한 장(`image`, `caption`) |
| `quote` | 가운데 큰 인용(`> …` 줄들 + 출처 문단) |

### 글

`# 제목`, `## 부제`, `### 소제목`, `- 목록`(들여 쓰면 하위), `1. 번호 목록`(중간에 다른 블록이 끼어도 번호가 이어짐), `- [ ] 체크리스트`, `**굵게**`, `*기울임*`, `` `코드` ``, `[링크](주소)`, `![설명](img/그림.png)`, 표(`| 머리 | … |` + `|---|---|`), `> 인용`, ```` ``` ```` 코드 블록.

### 블록(`:::` 로 열고 `:::` 로 닫음)

| 블록 | 쓰임 | 쓰는 법 |
|---|---|---|
| `::: cards` | 카드 2~8장 | `### 카드 제목` 아래에 내용, 카드마다 `###` |
| `::: cols` | 두 칸 | 왼쪽 내용 → `+++` → 오른쪽 내용(그림 가능) |
| `::: flow` | 화살표 흐름도 | `- 단계` 줄들(5개 안팎) |
| `::: note` | 아래쪽 강조 상자 | 문장·목록 |
| `::: cmd` | 명령어 상자 | 줄 그대로, `# 설명`은 회색 |
| `::: math` | 수식 한 줄(가운데) | LaTeX 그대로. 아래 "수식" 참고 |
| `::: media` | 소리·영상·YouTube | 아래 "소리·영상·YouTube" 참고 |
| `::: presenter` | 첫 장 발표자 상자 | `**발표 · 이름**` / 빈 줄 / 소속 / 빈 줄 / 홈페이지 |
| `::: html` | HTML 그대로(도식) | 아래 7장의 클래스 사용. `src="img/…"` 그림도 파일 안에 들어감 |
| `::: notes` | 발표자 노트(N 키) | 화면에는 안 보임 |

### 수식 (`$…$`, `::: math`)

수식은 LaTeX 문법으로 쓰고 [MathJax](https://www.mathjax.org)가 그립니다.

```markdown
평균은 $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$ 입니다.     ← 글 안 수식

::: math
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                    ← 따로 한 줄(가운데)
:::
```

- **글 안 수식**은 `$` 두 개 사이에 씁니다. 목록, 표, 강조 상자, 제목, 발표자 노트 어디서나 됩니다. 여는 `$` 바로 뒤와 닫는 `$` 바로 앞에는 빈칸을 두지 않습니다.
- **따로 보일 수식**은 `::: math` 블록에 씁니다. 블록 안에서 빈 줄로 나누면 수식이 여러 개가 됩니다. 여러 줄을 맞추려면 `\begin{aligned} … \end{aligned}`를 씁니다.
- **글자 달러**는 `\$`로 씁니다(예: `\$5`). "$5와 $10"처럼 닫는 `$` 뒤에 숫자가 오는 경우는 수식으로 보지 않습니다. `$x$는`처럼 뒤에 한글이 붙는 것은 괜찮습니다.
- **자주 쓰는 문법**: 분수 `\frac{a}{b}`, 근호 `\sqrt{x}`, 위·아래 첨자 `x^2`, `x_i`, 합 `\sum_{i=1}^{n}`, 그리스 문자 `\alpha`, `\Lambda`, 곱셈·나눗셈 `\cdot`, `\times`, `\div`, 큰 괄호 `\left( … \right)`, 수식 안의 보통 글자 `\mathrm{F1}`, `\text{표준편차}`.
- **파일 크기**: 수식이 하나라도 있으면 MathJax(약 2.3MB)가 HTML 안에 들어가 인터넷 없이도 보입니다. 수식이 없는 발표에는 들어가지 않습니다. `--link`로 만들면 넣지 않고 CDN을 참조합니다(인터넷 필요).
- **점검**: `?check`는 수식이 다 그려진 뒤에 결과를 보여 줍니다.

### 소리·영상·YouTube (`::: media`)

첫 줄은 파일 경로나 주소, 다음 줄부터 설정(모두 선택)입니다.

```markdown
::: media
media/인터뷰.mp3
caption: 2026년 인터뷰 중 일부
autoplay: 1
:::

::: media
https://www.youtube.com/watch?v=jNQXAC9IVRw
start: 5
caption: 5초부터
:::
```

| 설정 | 뜻 |
|---|---|
| `caption:` | 아래 설명 |
| `autoplay: 1` | 이 장에 들어오면 바로 재생(YouTube는 웹 주소로 열었을 때만) |
| `loop: 1` | 반복 재생(소리·영상 파일) |
| `start: 초` | YouTube 시작 위치(주소의 `t=`도 인식) |
| `poster: img/표지.jpg` | 영상 재생 전 보일 그림 |
| `height: 320` | 영상·YouTube 최대 높이(px) |
| `link: 1` | 파일을 HTML에 넣지 않고 경로로 참조(큰 영상용. 이 경우 `media/` 폴더를 함께 공유) |

- **형식**: 소리 mp3·m4a·aac·wav·ogg·flac, 영상 mp4·m4v·webm·mov·ogv(브라우저마다 mov·flac 지원이 다를 수 있으니 mp3·mp4 권장), YouTube 주소(`watch?v=`, `youtu.be/`, `shorts/`, `embed/`, `live/`) 또는 11자 영상 ID.
- **발표 중**: 장을 넘기면 소리·영상이 저절로 멈춥니다. **P 키**로 그 장의 첫 소리·영상을 재생/멈춤. 플레이어를 누른 상태에서는 스페이스·좌우 키가 플레이어 조작에 쓰입니다(넘기려면 화면 빈 곳을 누른 뒤).
- **용량**: 소리·영상 파일도 그림처럼 HTML 안에 들어가 파일이 그만큼 커집니다(합계 50MB가 넘으면 만들 때 경고). 큰 영상은 `link: 1`.
- **YouTube 주의**: YouTube는 2025년부터 웹 주소(Referer)가 없는 곳에서 재생을 막아(오류 153), **발표 파일을 더블클릭해 열면 "여기서 재생"이 막힐 수 있습니다.** 그때는 카드의 **"YouTube에서 열기"**를 누르거나, `python3 build.py 발표.md --serve`로 `http://localhost`에서 열면 슬라이드 안에서 재생됩니다. 웹 서버(학교 홈페이지 등)에 올린 발표도 슬라이드 안에서 재생됩니다. 인터넷 연결이 필요합니다.

## 7. 도식용 HTML 클래스 (`::: html` 안에서)

예시 `slides.md`의 "노드와 화살표 도식", "휴대폰 화면 틀" 장을 복사해서 고치는 것이 가장 쉽습니다.

- **노드와 화살표**: `div.tun` 안에 `div.tun-node`(`user` 흰색 / `cf` 주황 / `mac` 파랑) → `div.tun-link` 안에 `div.tun-arrow`(`r` 오른쪽, `l` 왼쪽, `out` 주황 점선) → 노드. 노드 안 `div.ico`(이모지), `b`(이름), `span`(설명), `div.inner`(안쪽 상자, `cfd`·`db` 색).
- **여는 방식에 따라 보이는 글**: `div.only-file`은 파일로 열었을 때만, `div.only-web`은 웹 주소(`--serve` 등)로 열었을 때만 보입니다. `openmode` 클래스를 함께 주면 안내 상자 모양이 됩니다.
- **휴대폰 틀**: `div.phones`(`sm`이면 작게) 안에 `div.phone-wrap` → `div.phone` + `div.phone-cap`. 화면은 `img.screen`(세로 390×844 비율 캡처). 덮개 `div.dim`, 단계 번호 `span.stepno`, 아래 안내 `p.mock-tag`.
- **브라우저·메뉴 그림**: 아이폰 아래 막대 `div.sbar`, 공유 시트 `div.sheet > div.row`(`hl` 강조), 홈 화면 `div.home-screen > div.app`(`ours`), 안드로이드 주소창 `div.cbar` + 메뉴 `div.cmenu`, PC 창 `div.pc > div.pc-bar + div.pc-body` + 대화상자 `div.pc-dialog`. 강조할 곳에 `hl` 클래스(주황 테두리).

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 그림이 안 보임 | 경로가 md 파일 기준 `img/파일.png`인지, 파일 이름(대소문자)이 맞는지. 만들 때 `! 그림 없음` 경고가 나옴 |
| 글자가 너무 작아짐 | `?check`로 확인하고 내용을 줄이거나 나누기 |
| 표가 길다 | 6줄 안팎으로, 넘치면 두 장으로 |
| 로고를 빼고 싶다 | 머리말에 `logo: none`(첫 장과 각 장 오른쪽 위 로고가 모두 빠짐) |
| 디자인 색을 바꾸고 싶다 | `build.py`의 CSS 맨 위 `:root`의 색 값(`--navy`, `--blue`, `--violet`, `--teal`)을 고친다(모든 발표에 적용됨) |
| 파일이 너무 크다 | 그림을 jpg로 줄이기(가로 1600px 정도). 편집 중에는 `--link`로 그림을 넣지 않고 빠르게 확인 |
| `python3` 명령이 없다(Windows) | `py build.py …` 또는 python.org에서 파이썬 설치 |
| YouTube가 "오류 153" | 파일로 열면 생기는 제한. "YouTube에서 열기" 또는 `--serve`로 열기 |
| 소리·영상이 재생되지 않음 | 만들 때 `! 미디어 없음` 경고 확인(경로는 md 기준 `media/…`), mp3·mp4로 바꾸기 |
| 수식이 `$…$` 글자 그대로 보임 | 여는 `$` 뒤나 닫는 `$` 앞에 빈칸이 있는지, 닫는 `$` 바로 뒤에 숫자가 붙었는지 확인 |
| 수식 자리에 빨간 글씨가 나옴 | LaTeX 문법 오류(중괄호 짝, 명령 이름). 빨간 글씨에 마우스를 올리면 이유가 보임 |
| `! MathJax 를 내려받지 못해` 경고 | `vendor/mathjax/tex-svg-full.js`가 없고 인터넷도 안 되는 경우. 템플릿 폴더를 통째로 복사했는지 확인 |
| HTML 파일이 너무 크다(영상) | 큰 영상에 `link: 1` → `media/` 폴더를 함께 공유 |
